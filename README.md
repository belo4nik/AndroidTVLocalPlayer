# Local Player TV — проект Android TV

Нативное приложение для Android TV / Android 11+. Не использует браузер и WebView.
Воспроизведение выполняется через AndroidX Media3 (ExoPlayer).

## Что реализовано
- Настройка IP-адреса и порта сервера внутри приложения; адрес сохраняется.
- Загрузка списков `/api/videos` и `/api/music` с вашего `server.py`.
- Навигация по спискам пультом телевизора с подсветкой активного элемента.
- Воспроизведение видео по HTTP с поддержкой Range-запросов сервера.
- Отдельный ExoPlayer для фоновой музыки; переключение видео не сбрасывает плейлист музыки.
- Случайный следующий музыкальный трек.

## Сервер
На компьютере запустите `python server.py`. В папках рядом с ним:
- `videos/` — видео;
- `music/` — музыка.

Компьютер и телевизор должны находиться в одной локальной сети. Узнайте LAN-IP компьютера и в настройках APK укажите, например:
`http://192.168.1.100:8080`

## Сборка APK через GitHub Actions (без Android Studio)
1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое** папки `AndroidTVLocalPlayer` в корень репозитория (включая скрытую папку `.github/workflows/build.yml`).
3. Перейдите во вкладку **Actions** и скачайте готовый `app-debug.apk` из блока **Artifacts**.

## Сборка APK локально через Android Studio
1. Откройте в Android Studio папку `AndroidTVLocalPlayer`.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
